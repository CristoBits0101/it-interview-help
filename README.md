# IT Interview Help

Web estática responsive para preparar entrevistas técnicas y repasar ingeniería de software. Construida con Astro 7, TypeScript y CSS; sin backend, cuentas ni servicios de IA necesarios para usarla.

## Home y contenido

Home permite elegir un área profesional y uno de sus perfiles y una etapa desde Trainee o Becario hasta Senior. La etapa muestra conocimientos recomendados, bases previas y objetivos prácticos con enlaces al contenido disponible. Amplía tu Alcance enlaza recursos externos en inglés sobre responsabilidades y competencias para todos los puestos. Los puestos se seleccionan únicamente en Home; el menú lateral organiza disciplinas y conocimientos. Las opciones de especialización, liderazgo y gestión no representan una jerarquía profesional universal.

Home presenta el encabezado «Prepara tu próxima entrevista técnica» y una orientación breve. Conserva los cuatro contadores y los selectores de área, profesión y etapa. El menú reúne seis grupos: Sistemas Informáticos, Ciberseguridad, Interacción Persona-Computadora, Ingeniería de Software, Tecnologías de Datos e Inteligencia Artificial. Las bases se integran en sus ámbitos y se comparten cuando corresponda. El orden y los años de las etapas orientan el aprendizaje sin imponer una progresión profesional universal.

El catálogo publicado incluye Software Design con 19 conceptos en cuatro módulos y Aplicaciones de IA Generativa con 104 conceptos en diez páginas temáticas. El glosario recoge los cien términos del README de prácticas más cuatro fundamentos acordados. El contenido disponible se define en `src/app/data/published-catalog.ts`; subir cambios al repositorio no publica por sí mismo la web alojada. Las demás áreas mantienen sus ramas visibles y sus hojas sin contenido deshabilitadas.

El catálogo fuente conserva estas rutas. La navegación publicada permite abrir Software Design y Generative AI Applications:

## Privacidad

**ES:** Antes de leer o guardar preferencias se solicita una decisión explícita. La única excepción es leer el idioma existente para traducir la solicitud sin autorizar otros datos ni escrituras. «Guardar mis preferencias» permite recuperar datos anteriores y recordar idioma, progreso, etapa, menú y sonido en este navegador y origen. «Continuar sin guardar» elimina los datos propios anteriores y conserva únicamente el rechazo en `tech-training:storage-consent:v1` para no volver a preguntar. Cerrar el diálogo no autoriza el guardado. El interruptor de Preferencias permite revocarlo o guardar el estado actual. No se utilizan cookies, seguimiento ni sincronización remota.

**EN:** An explicit decision is requested before reading or saving preferences. The only exception is reading the existing language to translate the request without authorizing other data or writes. “Save my preferences” allows previous data to be restored and language, progress, stage, menu and sound to be remembered in this browser and origin. “Continue without saving” deletes previous data belonging to this app and retains only the refusal in `tech-training:storage-consent:v1` so the question is not repeated. Closing the dialog does not authorize saving. The switch in Preferences allows saving to be revoked or the current state to be saved. Cookies, tracking and remote synchronization are not used.

**ES:** Sin guardado o si el almacenamiento falla, la configuración funciona en memoria mientras el documento permanece abierto y durante su navegación interna. Una recarga o la carga de otro documento empieza con los valores predeterminados cuando no se permite guardar salvo la lectura autorizada del idioma existente si aún no hay decisión. No se borra almacenamiento ajeno. Las restricciones del navegador pueden impedir guardar la decisión o borrar datos y se comunica el fallo. Esta elección no controla la caché propia del navegador ni constituye una certificación legal. Las tipografías se sirven desde la propia web.

**EN:** Without saving or if storage fails, settings work in memory while the document remains open and during its internal navigation. Reloading or loading another document starts with defaults when saving is not allowed except for the authorized reading of an existing language when no decision has been made. Other applications’ storage is not deleted. Browser restrictions may prevent saving the decision or deleting data and the failure is reported. This choice does not control the browser’s own cache or constitute legal certification. Fonts are served by the website itself.

**ES:** La aplicación genera HTML estático. JavaScript habilita la selección de perfil y etapa, la navegación entre módulos, búsqueda, progreso y repaso. Sin JavaScript el contenido sigue accesible y no se guardan preferencias. Con aceptación, el área, el puesto y el retorno de navegación usan almacenamiento de sesión; el idioma, el progreso, la etapa, las ramas y el sonido usan almacenamiento local. Los sonidos están desactivados por defecto y sus archivos se sirven desde la propia web.

**EN:** The application generates static HTML. JavaScript enables profile and stage selection, navigation between modules, search, progress and review. Without JavaScript, content remains accessible and preferences are not saved. With acceptance, area, role and return navigation use session storage; language, progress, stage, branches and sound use local storage. Sounds are off by default and their files are served by the website itself.

Las dependencias Python del material de referencia son contexto para la ruta Generative AI Applications; no son necesarias para ejecutar esta web.
